
\section{Reproduction}
\label{app:reproduction}

The source code, the proofs, the raw results and the scripts are in the repository of the thesis, which is available at \url{https://gitlab.lrz.de/masters2026/master-thesis-proover} and mirrored at \url{https://github.com/AlexanderGiller/master-thesis-proover}, and the commit used for the measurements is \EvalCommit.
The verifier needs Python~3.11 or newer and \texttt{lark}, and the external prover Vampire is found in the search path or configured with \texttt{EXTERNAL\_ATP\_BINARY} or \texttt{EXTERNAL\_ATP\_COMMAND}.

\begin{verbatim}
python -m pip install -r requirements.txt -r requirements-dev.txt
python main.py ProoVer2026/PRV/PRV010+1.s        # one proof
python main.py -d ProoVer2026/PRV                # directory with scoring
python main.py --quiet ProoVer2026/PRV/PRV010+1.s
pytest
python scripts/eval_all.py --parts all --reps 3
\end{verbatim}

\section{Example Report}
\label{app:reports}

For every proof, the verifier prints one block per check and ends with the SZS status.
The following output is the shortened report for the invalid proof \texttt{PRV002+1}, whose negated conjecture is a renamed copy of the conjecture instead of its negation.
Most blocks without a finding are omitted, and the formulas are abbreviated.

\section{Results per Proof}
\label{app:per-proof}

The results of the measured run (Section~\ref{subsec:eval-setup}) for every proof of all sets, including the nine deprecated pairs, are in the file \href{https://github.com/AlexanderGiller/master-thesis-proover/blob/main/results/eval/per_proof.csv}{\texttt{results/eval/per\_proof.csv}} of the repository, with the expected result, the verdict, the number of steps and prover calls, the prover time, the median wall-clock time and the peak memory of each proof.
For the ProoVer set, Table~\ref{tab:eval-matrix} summarizes them.
Tables~\ref{tab:app-tst} and~\ref{tab:app-ext} list the TST set and the Extra set, which are not described elsewhere proof by proof.
The time is the median wall-clock time of three runs, including the start-up of the interpreter. The column ``Result'' compares the status with the expected result, and ``abstain'' denotes \texttt{Unknown} or \texttt{Timeout}, which score zero. The status \texttt{Error} marks proofs that the parser rejects, for which the verifier prints \texttt{VerifiedBad}. ``Edge case'' marks the proofs with an open expected result, five in the TST set and \EvalExtraEdge{} in the Extra set, which are not counted. The only disagreement in the TST set, \texttt{TST043}, is discussed in Section~\ref{subsec:eval-correctness}.
