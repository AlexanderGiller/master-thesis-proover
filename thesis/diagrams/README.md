# UML diagrams

This folder contains PlantUML source files for the proof checker architecture.

## Files

- `class_diagram.puml`: high-level class/module diagram
- `sequence_diagram_check_proof.puml`: sequence for one proof-check run

## Render locally

If PlantUML is available in your environment:

```powershell
plantuml "C:\Git\master-thesis-proover\thesis\diagrams\class_diagram.puml"
plantuml "C:\Git\master-thesis-proover\thesis\diagrams\sequence_diagram_check_proof.puml"
```

This generates PNG files next to the `.puml` files.
